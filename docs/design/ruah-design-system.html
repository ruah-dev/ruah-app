06 · Phantom

The mascot. A character, not a logo.

Ruah's Phantom is a rendered SVG character with expression states tied to product events. Body color comes from the palette (--teal-400 by default, swappable per state). Pupils are --teal-500 — never black. Reduced-motion: keep visible, disable animation.

08 · Claude Code skill

Copy the block below into your repo's CLAUDE.md at the project root. Any Claude Code session inherits the Ruah brand system automatically — tokens, conventions, component primitives, and do's/don'ts.

CLAUDE.md · Ruah brand system
# Ruah Brand System

You are designing and building UI for Ruah — an open-source CLI that orchestrates parallel coding agents (Claude Code, Aider, Codex). Adhere to the system below for every new surface, page, and component. When in doubt, copy existing patterns rather than invent.

## Voice

- Concrete over abstract. Name the agents, name the outcome ("zero merge conflicts"), show the diff.
- Italicized serif carries emphasis. Never bold inside a serif headline.
- Eyebrows (mono, uppercase, 0.16em tracking) orient the user. Use at most one per section.
- No emoji. No exclamation points. No "unleash", "supercharge", "revolutionize".

## Typography

- Display/headings: Instrument Serif, weight 400, letter-spacing -0.02em.
- Body/UI: DM Sans, 15/1.6 default, 13/1.55 small.
- Mono/technical: Geist Mono, 11–13px, uppercase for eyebrows (letter-spacing 0.16em).
- Scale (px/line-height): 72/76 display · 48/52 h1 · 32/36 h2 · 22/26 h3 · 15/24 body · 13/20 small · 11 eyebrow.

## Colors — 6 semantic roles

Each role owns one hue. Never reuse a semantic color for an unrelated purpose.

- --teal-400 #00d2b9 — brand, primary actions, default Phantom body.
- --lavender-400 #b594f5 — AI / agent activity, thinking states, experimental.
- --sage-400 #7fb069 — success, merged, passing CI.
- --amber-400 #e5a84b — warnings, stale branches, deprecation.
- --coral-400 #f07068 — errors, failures, destructive actions.
- --slate-400 #5b6b88 — info, metadata, queued/inactive.

Each has a 4-step scale: -200 (tint), -300, -400 (base), -500 (shade). Use -300/-500 for hover states.

## Themes

Three themes, all built from the same neutral surface tokens:

- dark (default): bg #111110, fg #f0eee9. Warm charcoal, cream text.
- light: bg #faf9f7, fg #191918. Same cream family.
- contrast: bg #000, fg #fff. WCAG AAA. For accessibility mode.

Theme tokens: --bg, --surface-1/2/3/4, --fg, --fg-muted/subtle/dim, --border, --border-strong.

## Spacing / Radii / Shadows

- 4px base scale: --sp-1 (4) through --sp-24 (96).
- Radii: --r-xs (4), --r-sm (6), --r-md (10), --r-lg (16), --r-xl (24), --r-pill (999).
- Shadows: --shadow-sm, --shadow-md, --shadow-lg.

## Phantom mascot

The Phantom is a rendered SVG character — body color from palette, white eyes with teal pupils (never black). Expressions are product-event-driven:

- idle — floating, blinking. Default.
- thinking — horizontal squint eyes.
- tracking — pupils follow cursor.
- loading — mint body, pupils bounce.
- success — sage body, sparkle-star eyes.
- warning — amber body, ! emblem.
- error — coral body, X eyes.

Under prefers-reduced-motion, keep Phantom visible but static. Never remove him. Eyes are ALWAYS white with no black — pupils, when present, use the character's -500 shade; The Face (cli) has plain white eyes with NO pupils.

## Phantom family — one character per tool

Every tool is a Phantom with a fixed color and personality. Use them on tool pages, docs sidebars, and error/empty states:

- cli — The Face — cream #dedad3. The router; neutral because it's all of them at once. Plain white eyes, no pupils.
- orch — The Conductor — teal-400. Parallel agents, zero collisions.
- guard — The Bodyguard — coral-400. Blocks dangerous commands/secrets. Furrowed coral-dark brows.
- verify — The Referee — sage-400. Proves work is done. Checkmark eyes.
- opt — The Accountant — amber-400. Token/cost analysis. Squinting eyes.
- watch — The Storyteller — lavender-400. Session → shareable HTML replay. Big wide eyes.
- eval — The Judge — slate-400. N-agent comparison. Asymmetric weighing eyes.
- conv — The Shapeshifter — mint #88e6d7. API → MCP tools. Spiral eyes.

Nav groups: Build (conv) · Run (cli, orch) · Trust (guard, verify) · Understand (opt, watch, eval).

## Docs rules

- 3-column layout: grouped sidebar (role groups above) / article max 720px / on-page TOC.
- Every sidebar tool link carries its character's color dot; every tool page opens with its Phantom + role eyebrow + install command.
- Callouts use the alert component (role-colored 3px left border). Command references are tables, not prose.
- Breadcrumbs mono 10px; current page in teal. Prev/next pager at article foot.

## Component rules

- Buttons: primary (fg on bg), teal (brand accent), ghost (outline), danger (coral). Radius --r-md, 10px 18px padding. Always include focus-visible ring in --teal-400.
- Badges: pill, mono 10px uppercase, border-matching-color. One per semantic role.
- Inputs: --surface-1 background, --border-strong border. Focus: teal border + 3px soft teal ring.
- Cards: --surface-1 bg, --border border, --r-lg radius.
- Alerts: 3px left border in role color, --surface-2 bg, bold colored strong text.

## Don'ts

- No gradients on backgrounds. Solid surfaces only.
- No rounded-left-border accent cards (overused AI slop).
- No purple-pink gradient buttons. Use solid teal-400 or solid --fg.
- No emoji in marketing copy.
- No versioning before trust (don't show "v1.1.1" near CTAs).
- No uppercase-eyebrow monopoly — allow serif italic subheads to vary rhythm.

## Files

- ruah-tokens.css — drop-in CSS variables (all palettes + themes).
- ruah-tailwind.config.js — Tailwind v3 preset mapping tokens.
- ruah-phantom.svg — SVG symbol with expression variants.

Import tokens with:
@import "./ruah-tokens.css";
<html data-theme="dark" data-palette="default">

When building a new surface: start from :root tokens, reach for the component primitives, only invent when the system genuinely doesn't cover the case — and then add the new primitive back to the system.
